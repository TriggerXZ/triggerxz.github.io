FAQ

What exactly counts as an "agent"?

Anything that takes a repetitive workflow and runs it without a human in the loop: a script that generates release notes, a hook that blocks dangerous commands, a workflow that summarizes the week, a bot that reviews pull requests. If it has inputs, logic, and outputs — it can probably be an agent.

How do I know it actually works?

Every deliverable ships with an automated test suite — the same way I build my own tools (51/51 tests passing across 7 repos). You can run the tests yourself before you accept the project. No trust required, just pytest.

What if I need changes after delivery?

Every plan includes a support window (30/60/90 days). Small tweaks are free within that window. Bigger changes get a quote — usually cheaper than a new project since the foundation already exists.

Do you sign NDAs?

Yes. I'm a solo builder, but I work like a professional: NDA available on request, no sharing of your code or data, and everything you pay for is 100% yours.

What's your stack?

Python, bash, JavaScript, n8n, GitHub Actions, the Claude API, and whatever your stack requires. I've shipped zero-dependency bash tools and multi-step n8n workflows — I adapt to your tools, not the other way around.
